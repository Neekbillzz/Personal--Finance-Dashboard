# Fintech Dashboard MVP

A responsive, full-stack fintech dashboard web application built to track user transactions, manage income and expenses, and compute real-time financial metrics dynamically.

## 🚀 Features
- Dynamic Financial Calculations: Automatically computes Total Income, Total Spent, and Net Current Balance on the fly from transaction data.
- Robust Amount Parsing: Utilizes regular expressions to reliably clean and format string currencies.
- Live CRUD Operations: Supports real-time transaction fetching and deletion with instant UI synchronization.
- Responsive Interface: Styled cleanly with Tailwind CSS for a modern mobile/desktop-friendly layout.

## 🛠️ Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Tooling: Git, VS Code, Postman
